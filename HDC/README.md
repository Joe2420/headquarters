# Headquarters Development Constitution (HDC)

**Package:** HDC v0.1  
**Status:** Active — final pre-code governance package  
**Classification:** Engineering Control  
**Owner:** Founder / Chief Architect  

The Headquarters Development Constitution defines how implementation is allowed to happen.

HDR defines what Headquarters is. HTB defines how Headquarters is structured. HIG defines implementation guidance. HDC defines how engineers and Codex must behave while building it.

This folder is mandatory before production coding begins.

## Core Rule

Codex is not the architect of Headquarters. Codex is the implementation engineer.

If implementation requires architectural invention, Codex must stop and request approval through an Architecture Change Request.

## Development Mode

All coding work must be divided into 2–4 hour engineering tasks. Each task must end with a reviewable deliverable and an explicit approval gate. Codex must not continue to the next task without approval.
