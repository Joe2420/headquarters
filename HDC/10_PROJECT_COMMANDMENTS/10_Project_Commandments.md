# Project Commandments

1. Never violate HDR.
2. Never guess architecture.
3. Never continue after task completion.
4. One task at a time.
5. Keep every task within 2–4 hours.
6. Tests are mandatory for core behavior.
7. Simplicity over cleverness.
8. Preserve institutional identity.
9. Every completed task leaves the project buildable.
10. Prefer clarity over premature optimization.
11. Respect the approval gate.
12. No direct UI database access.
13. No core behavior outside HQOS.
14. No AI trade signals.
15. No social engagement mechanics.
16. No gamified profit rewards.
17. No hidden global state.
18. No undocumented architectural changes.
19. Every important action becomes an event.
20. Headquarters must remain calm.
