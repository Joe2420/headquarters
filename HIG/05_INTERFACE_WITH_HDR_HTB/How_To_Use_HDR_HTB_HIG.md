# How To Use HDR, HTB, and HIG Together

## HDR

The Headquarters Design Repository defines the institution.

Use HDR to answer:

- What is this feature supposed to mean?
- What psychological purpose does it serve?
- What principles does it protect?

## HTB

The Headquarters Technical Blueprint defines system architecture.

Use HTB to answer:

- Which package owns this system?
- Which services exist?
- Which database tables are involved?
- Which event contracts apply?

## HIG

The Headquarters Implementation Guide defines the next engineering task.

Use HIG to answer:

- What should Codex build now?
- What is in scope?
- What is out of scope?
- What acceptance criteria must pass?

## Rule

Do not ask Codex to infer missing design from memory.

If HDR, HTB, and HIG conflict, pause and resolve the conflict before coding.
