# XP System

Status: architecture documentation from ARCH-TASK-0001.
Source: Headquarters Journal Architecture Handoff v0.1.

## Purpose

The Academy XP System turns production `journey_entries` into behavior-based growth architecture. It tracks professional development, not profit achievement.

## Source Mapping

| Source Field | Headquarters Meaning |
|---|---|
| `progress_value` | Cumulative progress / XP-like score. |
| `change_amount` | XP delta. |
| `title` | Growth event title. |
| `description` | Growth reflection. |
| `milestone_reached` | Academy or Recognition milestone flag. |

## XP Principles

- XP is awarded for behavior, discipline, reflection, and professional improvement.
- XP may decrease when behavior violates risk or plan discipline.
- XP is contextual evidence, not moral judgment.
- Profit is not the default basis for XP.

## Positive Signals

- Journal completion.
- Mission debrief completion.
- Plan adherence.
- Stop-loss respect.
- Right-sized risk.
- Restraint from low-quality trades.
- Clear mistake recognition.

## Negative Signals

- Plan break.
- Revenge trading.
- Ignored stop logic.
- Chasing.
- Trading while distracted.

## Guardrail

The XP System must feel institutional and quiet. It must not turn growth into gamified pressure.

## Deferred Work

No XP engine, UI, scoring algorithm, persistence model, or event behavior is approved here.
