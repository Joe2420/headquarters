# Golden Path Test Cases v0.3

Status: Engineering Ready
Owner: QA

## Golden Path 1: No Trade Mission
Operator reports for duty, completes briefing, observes, takes no trade, completes debrief, archives mission successfully.

## Golden Path 2: Authorized Deployment
Operator completes briefing, requests authorization, receives approval, declares external deployment, completes mission, archives reports.

## Golden Path 3: Guardian Return To Base
Operator reaches objective, Guardian recommends Return to Base, operator accepts, mission archives as protected.

## Golden Path 4: Recovery Day
Readiness compromised, Medical recommends Recovery Day, mission records recovery instead of deployment.

## Acceptance Criteria
All golden paths pass in automated end-to-end testing before Milestone 1 is accepted.
