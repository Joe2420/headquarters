# Startup to First Mission Flow v0.3

Status: Engineering Ready
Owner: UX

## Flow
1. App launch.
2. Boot sequence begins.
3. System integrity check.
4. Archives status resolved.
5. Departments online.
6. Security Checkpoint displayed.
7. Operator selects Report for Duty.
8. Blast door transition.
9. Entrance Hall.
10. Command Chair prompt.
11. Operator assumes command.
12. Mission Board appears.
13. Morning Briefing begins.
14. Ready Room available.
15. Observation Room begins mission work.

## UX Rules
- No market data shown before Command Chair.
- No PnL shown in startup flow.
- Boot sequence must be skippable only in developer mode or accessibility mode.

## Acceptance Criteria
The first run flow works with an empty database and creates the first Operator profile safely.
