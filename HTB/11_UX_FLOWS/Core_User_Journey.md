# Core User Journey

    **Owner:** UX  
    **Status:** Engineering Blueprint  
    **Baseline:** HDR v1.0 Design Freeze  
    **Purpose:** Convert the locked Headquarters design into buildable implementation guidance.

    ---


Primary daily journey:

```text
Boot Sequence
→ Security Checkpoint
→ Blast Doors
→ Entrance Hall
→ Command Chair
→ Mission Board
→ Ready Room
→ Observation Room
→ Authorization Terminal
→ External Broker/Trading Platform
→ Mission Management
→ Return To Base
→ Debrief Theater
→ Archives
→ Shutdown
```

The app does not open on charts. The Operator is prepared before market interaction.

    - No new product philosophy is introduced here.
    - The document gives Codex/developers actionable engineering direction.
