# Mission Authorization Flow v0.3

Status: Engineering Ready
Owner: UX / Operations

## Flow
1. Operator observes possible setup externally.
2. Operator returns to War Room.
3. Operator opens Authorization Terminal.
4. Operator completes deployment checklist.
5. Authorization request event dispatched.
6. Council evaluates.
7. Guardian checks risk.
8. Operations checks doctrine.
9. Commander synthesizes response.
10. Terminal displays Authorized or Not Yet Authorized.
11. If authorized, operator may deploy externally.
12. Operator manually declares deployment in Headquarters.

## Rule
Headquarters never places trades.

## Acceptance Criteria
Authorization can be completed without broker integration.
