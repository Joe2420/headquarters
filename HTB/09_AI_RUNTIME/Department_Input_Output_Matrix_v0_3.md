# Department Input Output Matrix v0.3

Status: Engineering Ready
Owner: Intelligence

| Department | Inputs | Outputs | Direct Operator Speech |
|---|---|---|---|
| Commander | Council consensus, mission state, operator model | one-sentence command response | Yes |
| Guardian | funded mode, risk, behavior, judgment reserve | intervention recommendation | Yes |
| Historian | archives, similarity search, doctrine history | historical evidence | Rare |
| Ghost | top-quality mission profile, current context | ideal behavior comparison | No direct criticism |
| Internal Affairs | debrief, event stream, inconsistencies | investigation case | Yes, post-mission only |
| Medical | readiness, recovery, fatigue | recovery recommendation | Yes |
| Engineer | system health, audits, logs | anomaly report, improvement recommendation | Rare |
| Academy | weakness patterns, campaign goals | course or drill assignment | Yes, non-mission |
| Intelligence | patterns, hypotheses, evidence | research case | No direct speech |

## Acceptance Criteria
No department may produce unrestricted free-form advice. Outputs are structured, typed, and confidence-scored.
