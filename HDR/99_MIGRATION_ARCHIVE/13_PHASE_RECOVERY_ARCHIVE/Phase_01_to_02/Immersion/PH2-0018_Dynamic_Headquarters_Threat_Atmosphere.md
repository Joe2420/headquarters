# PH2-0018 — Dynamic Headquarters Threat Atmosphere

**Recovery Phase:** Phase 1.3–2.0  
**Category:** Environment  
**Priority:** CORE  
**Status:** SPECIFIED  
**Owner:** Headquarters Architecture

## Purpose
Headquarters atmosphere changes with risk condition: Green, Yellow, Orange, Red, Black.

## Operator Experience
At Black, all but END DAY disappears; charts are inaccessible through Headquarters.

## Engineering Implementation
Threat state drives room availability, lighting, sound, and UI simplification.

## Dependencies
Threat Engine; Guardian
