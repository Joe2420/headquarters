# PH2-0008 — Commander Voice Profile

**Recovery Phase:** Phase 1.3–2.0  
**Category:** Audio/AI  
**Priority:** CORE  
**Status:** SPECIFIED  
**Owner:** Headquarters Architecture

## Purpose
Commander voice must be calm, deep, deliberate, never theatrical or shouting.

## Operator Experience
When heard, it feels dangerously calm and authoritative.

## Engineering Implementation
Voice output optional; text remains primary; max intervention limits apply.

## Dependencies
Commander; Audio Bible
