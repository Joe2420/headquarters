# Phase Recovery Index

This folder contains the phase-by-phase reconstruction pass for Headquarters HDR. It exists to prevent early architecture ideas from remaining only in conversation history.

## Current Coverage

- Phase 0.1–1.0: Initial identity, core metrics, mission workflow, and state machine.
- Phase 1.0–2.0: SOP layer, rule provenance, room-based operations, immersion, airlock, oath, Commander behavior, dynamic Headquarters, Mirror Room, Fallen Missions, and foundational culture.

## Rule

If a concept was introduced during the architecture conversation and is not yet assigned a permanent ID elsewhere, it is first recovered here. Later audit passes may move recovered items into their final volumes.


## Phase 03 to 04

Recovered in HDR v0.5. Contains Design Constitution, Internal Affairs, Engineering Philosophy, Behavioral Engine, Black Box, Mission Timeline, and cascade detection artifacts.
