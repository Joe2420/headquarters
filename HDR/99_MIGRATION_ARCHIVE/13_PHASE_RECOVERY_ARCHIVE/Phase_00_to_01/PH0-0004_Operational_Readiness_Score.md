# PH0-0004 — Operational Readiness Score

**Recovery Phase:** Phase 0.1–1.0  
**Category:** Behavior System  
**Priority:** CORE  
**Status:** SPECIFIED  
**Owner:** Headquarters Architecture

## Purpose
Measure whether the Operator is fit to deploy capital today.

## Operator Experience
Operator sees a 0–100 readiness classification with reasons and restrictions, not generic emotion labels.

## Engineering Implementation
Calculate from sleep, stress, confidence, energy, prior violations, streak, recovery, funded mode, and fatigue.

## Dependencies
Operator Model; Medical Officer; Mission Briefing

- The feature can be identified in the Master Index.
- The feature has a clear implementation path.
- The feature supports disciplined execution rather than entertainment.
- The feature can be tested through mission-state or UX acceptance checks.
