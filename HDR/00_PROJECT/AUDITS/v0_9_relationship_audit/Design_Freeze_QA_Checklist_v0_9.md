# HDR v0.9 — Design Freeze QA Checklist

Before HDR v1.0 Design Freeze, verify:

- [ ] Every recovered file has a canonical target.
- [ ] Every duplicate concept is merged or intentionally retained.
- [ ] Master Index is generated from actual repository files.
- [ ] Every P0 object has dependencies and acceptance criteria.
- [ ] Every room has UX, lighting, sound, state, and interaction notes.
- [ ] Every AI department has triggers, inputs, outputs, confidence, and voice/tone rules.
- [ ] Every major lifecycle has an end-to-end event trace.
- [ ] SQLite schema references all required archival objects.
- [ ] HQOS event bus covers mission, room, archive, and recommendation events.
