# PH0-0007 — Execution XP

**Recovery Phase:** Phase 0.1–1.0  
**Category:** Behavior System  
**Priority:** IMPORTANT  
**Status:** SPECIFIED  
**Owner:** Headquarters Architecture

## Purpose
Reward correct process, including non-actions, without turning Headquarters into a game.

## Operator Experience
Operator receives subtle recognition for good skips, patience, debriefs, planned losses, and stopping.

## Engineering Implementation
Log positive/negative process events; display only in institutional style, never arcade style.

## Dependencies
Recognition Office; Archives; Discipline Ledger
