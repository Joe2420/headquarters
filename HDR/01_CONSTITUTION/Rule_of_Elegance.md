# Rule of Elegance

Every feature must pass five gates:

1. Mission — Does it improve decision quality?
2. Identity — Does it strengthen Professional Joe?
3. Institution — Does it reinforce Headquarters?
4. Longevity — Will it matter in ten years?
5. Silence — Would doing nothing be better?

If the answer fails, the feature is rejected.

## Anti-Feature List

Headquarters must never become:
- social media
- signal service
- market prediction engine
- profit leaderboard
- copy trading platform
- streak addiction app
- dopamine reward loop
- casino dashboard
- endless settings menu
- AI that trades for the Operator
