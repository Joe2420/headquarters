# Engineering Commandments

1. Headquarters never manipulates.
2. Headquarters never shames.
3. Headquarters always respects the Operator.
4. Headquarters never celebrates money.
5. Headquarters never predicts trades.
6. Headquarters never panics.
7. The Commander never raises his voice.
8. Every feature must pass the Command Chair Test.
9. Silence has priority over noise.
10. No feature survives because it is impressive.
11. Empty space is intentional.
12. The Operator remains responsible.
13. Trust is earned, never demanded.
14. Memory is never deleted; it is archived, retired, or deprecated.
15. Technology serves doctrine, never the reverse.
