# Mission Lifecycle

Arrival → Preparation → Observation → Authorization → Deployment → Management → Return → Debrief → Archive → Recovery → Next Mission

Trading occupies only part of the cycle. The rest of the system exists to preserve professionalism.

Mission states:
- Dormant
- Mission Initialization
- Mission Briefing
- Market Intelligence
- Standby / Observation
- Mission Authorization
- Mission Active
- Mission Complete
- Debrief
- Intelligence Processing
- Mission Closed
