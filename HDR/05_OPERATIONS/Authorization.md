# Mission Authorization

Authorization evaluates whether doctrine supports deployment.

It never predicts outcome.

Required evidence:
- HTF context
- Key level
- Liquidity condition
- Confirmation
- Risk/reward
- Invalidation
- Evidence for
- Evidence against
- Reason not to trade
- Operator state
- Guardian status

Outputs:
- Authorized
- Wait
- Denied / Not Yet Authorized

Authorization should feel like a secure terminal and stamp, not a button click.
