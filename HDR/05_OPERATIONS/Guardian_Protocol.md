# Guardian Protocol

Guardian Protocol activates during funded/capital-protection mode.

Philosophy:
> You no longer own this capital. It has been entrusted to you.

Behavior changes:
- Darker, heavier visual state.
- Fewer profit metrics.
- More capital protection metrics.
- Longer override delays.
- Lower risk thresholds.
- Success Protocol activates after gains.
- Secure Vault option after objective reached.
- Weekend trading denied in funded mode.
- Return to Base emphasized.

Key systems:
- Capital Vault
- Guardian Integrity
- Guardian Bell
- Success Protocol
- Golden Week Protocol
- Operation Sunset
- Hall of Custodians
