# PH2-0014 — Mission Clock

**Recovery Phase:** Phase 1.3–2.0  
**Category:** Interface  
**Priority:** IMPORTANT  
**Status:** SPECIFIED  
**Owner:** Headquarters Architecture

## Purpose
Measure mission time and standby time as operational work.

## Operator Experience
Waiting timer validates patience instead of making it feel like wasted time.

## Engineering Implementation
Timers tied to mission state; displayed in Observation/Standby.

## Dependencies
HQOS; Observation Room
