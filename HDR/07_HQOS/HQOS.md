Everything reads one truth.
Everything synchronizes through mission state, operator model, doctrine library, archives, and event bus.

Core systems:
- Event Bus
- State Engine
- Mission Kernel
- Operator Model Service
- Archive Service
- Department Bus
- Heartbeat
- Background Services
- Night Operations
- Boot/Shutdown Sequences
