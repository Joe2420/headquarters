# State Engine

Single source of truth for active operational state.

States include:
- Dormant
- Booting
- Arrival
- ReadyRoom
- Briefing
- Observation
- WarRoom
- Authorization
- Deployment
- ActiveMission
- ReturnToBase
- Debrief
- Archive
- Recovery
- Closed
- NightOperations

Rooms, lighting, audio, AI behavior, and UI all react to state.
