# PH2-0015 — Heartbeat Mode

**Recovery Phase:** Phase 1.3–2.0  
**Category:** Environment  
**Priority:** IMPORTANT  
**Status:** SPECIFIED  
**Owner:** Headquarters Architecture

## Purpose
Make waiting feel calm with subtle radar sweep and optional low-frequency heartbeat.

## Operator Experience
Operator unconsciously slows down during periods of no action.

## Engineering Implementation
Ambient loop only in Standby/Observation; accessible mute option.
