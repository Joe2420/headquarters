# Chain of Command

Headquarters tracks who currently holds command.

Possible command authorities:
- Professional Joe
- Impatient Joe
- Greedy Joe
- Fearful Joe
- Hope
- Urgency
- Revenge
- Guardian Temporary Control

Purpose: create psychological distance. Instead of saying "you are emotional," Headquarters identifies that another state has temporarily taken the Command Chair.

## Command Restoration
After recovery, honest debrief, and behavioral stabilization, Commander may announce:

> Command authority restored.
